مشروع طمأنينة - Tamanina
========================

محتويات المشروع:
- index.html: التطبيق الكامل.
- manifest.webmanifest: تعريف تطبيق الويب القابل للتثبيت.
- sw.js: تخزين ملفات التطبيق للعمل دون اتصال بعد أول زيارة ناجحة.
- icon.svg: أيقونة التطبيق.

طريقة الرفع إلى GitHub:
1) افتح مستودع Tamanina-New.
2) اضغط Add file ثم Upload files.
3) ارفع جميع الملفات الأربعة مع هذا الملف إلى جذر المستودع.
4) اضغط Commit changes.

طريقة النشر:
- اربط المستودع مع Netlify.
- اجعل Publish directory هو الجذر (.) ولا تحتاج Build command.
- افتح رابط الموقع مرة واحدة مع الإنترنت حتى تُخزّن الملفات.
- بعد ذلك يمكن فتحه دون إنترنت من نفس المتصفح/التطبيق إذا كان WebView يحترم Service Worker.

ملاحظات مهمة:
- التخزين دون إنترنت يعمل بعد أول تحميل ناجح، وليس قبل أول فتح.
- الإشعارات هنا إشعارات ويب تجريبية عند فتح التطبيق/الصفحة. التذكير اليومي التلقائي حتى عندما يكون التطبيق مغلقاً يحتاج خدمة Push أو دعم إشعارات محلية من منصة التغليف مثل Median؛ لا تعتبر هذه النسخة قد فعّلت التذكير الخلفي التلقائي.
- عداد التسبيح والإعدادات تُحفظ محلياً على الجهاز.
